# Авторы и лицензии — сохранённое решение пользователя

26 октября 2026 года. Это обязательная памятка для следующего помощника.

**Сейчас не добавлять экран/пункт лицензий на главный экран игры.** Пользователь
хочет решить расположение позднее, при работе над интерфейсом. Допустим
ненавязчивый доступ из подходящего раздела; конкретное место пока не выбрано.
Не делать обязательный экран, который нужно пропускать перед полётом.

Отложено только оформление интерфейса. Уже сейчас сохранять в GitHub и
поставке необходимые лицензии, авторство и соответствующие исходники.
Текст «модель взята здесь» не заменяет выполнение GPL и не исправляет
неясные права исходного автора. Конвертация не отменяет условия.

## Реестр ресурсов

Для каждого фактически используемого ресурса вести: самолёт/компонент,
автор/указанный источник, URL, commit/версия, файлы, SHA-256, лицензия,
уведомления об изменениях, какие исходники предоставляются, что не выяснено.
Референсные фотографии, игровая геометрия, текстуры, звуки и код — отдельные
позиции, если у них разные источники/условия. Не копировать всё подряд.
