# Текущее задание: заменить Су-27 и МиГ-29

Замени нынешние модели Су-27 и МиГ-29 в нашей игре на геометрию из этих источников:

- **Су-27:** [репозиторий](https://github.com/FGMEMBERS/Su-27), [файл модели](https://raw.githubusercontent.com/FGMEMBERS/Su-27/a9c4863886a5835dfa4406698dd4557fbf72a3aa/Models/Su-27.ac).
- **МиГ-29:** [репозиторий](https://github.com/FGMEMBERS/MiG-29), [файл модели](https://raw.githubusercontent.com/FGMEMBERS/MiG-29/646e9f9d6b958773e69cbde74602642c91fcfcaf/Models/Mig-29.ac).

Берём только геометрию самолётов. Чужие текстуры, звуки и игровые системы
не переносим. Окраску делаем свою, лицензии и авторство сохраняем.

Переведи модели в формат нашей игры. Сразу подключи работающие шасси,
створки, фонари, управляющие поверхности, воздушные тормоза и форсаж.

Проверь пропорции, осмотри самолёты со всех сторон и проверь механизмы
в движении. Исправь щели, исчезающие детали и пересечения.

Сделай это в отдельной тестовой версии от последней рабочей сборки.
Готовые Су-47 и Су-57 сохрани. Старые версии не удаляй.

Дай через GitHub ZIP игры для Windows 32-bit, короткий отчёт, фотографии
и видео результата. Раздел лицензий в интерфейс сейчас не добавляй:
его место решим позже, документы и исходники сохраняем уже сейчас.
