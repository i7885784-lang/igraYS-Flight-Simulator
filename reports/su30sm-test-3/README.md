# Су-30СМ — тест 3

[Фото и видео, HTML](index.html) · [Ссылки и SHA-256](STATUS.json) · [Целевые проверки](CHECKS.json).

Главная причина чёрных выступов у фонаря исправлена: ниша переднего шасси ошибочно доходила до верхней части стекла. Её крыша теперь под полом, укладка передней стойки изменена. Разделены створки и щитки, добавлены ниша и привод тормоза, углублённые каналы двигателей; поправлены сопла и синее пламя. Оружие отключено по запросу пользователя. Нос не изменён, сглаживание выключено.

Один Game.zip содержит32/64 и остальные самолёты. Запуск после полной распаковки — Play_Su30SM.bat. Report.zip открывается локально через index.html; Sources.zip содержит полный движок/GLB/конвертер/историю. Релиз остаётся DRAFT: для загрузки нужна учётная запись владельца GitHub.

Сверка выполнялась по инструкции Звезда7314 именно Су-30СМ с разрешения пользователя. Заводской точности размеров и кинематики не заявляется; интерьер и физика пока игровые. Проверка конечной модели пользователем впереди.
