# Личный тест №4: Су-34

**Личная сборка готова:** [скачать игру Windows 32-bit](https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/download/untagged-5bb1fabfb0a1bd0487b1/YSFlight_Playtest_4_Private_Su34_32bit.zip) · [исходники](https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/download/untagged-5bb1fabfb0a1bd0487b1/YSFlight_Playtest_4_Private_Su34_Sources.zip) · [страница закрытого черновика](https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/tag/untagged-5bb1fabfb0a1bd0487b1). Войти в GitHub под владельцем репозитория. Без входа будет 404 — это проверено. Распаковать в новую папку: **Play_Su27.bat** или **Play_Su34.bat**. Черновик не публиковать до выяснения прав.

GitHub Actions заново собрал модель из закреплённого источника: геометрия и состояния совпали с проверенной локальной сборкой. CRC обоих ZIP, скачивание с авторизацией и SHA-256 проверены. [Подтверждение и суммы именно выданных архивов](STATUS.json); local-package-checks.json относится к отдельной локальной упаковке тех же проверенных данных и имеет другие суммы ZIP.

Публичная игра с Су-27 уже доступна: [ZIP Windows 32-bit](https://raw.githubusercontent.com/i7885784-lang/igraYS-Flight-Simulator/5e5aa0a/downloads/YSFlight_Playtest_4_32bit.zip). [Отчёт Су-27 / МиГ-29](../playtest-4/REPORT.md).

Су-34 — личный прототип на геометрии fantazer_rnd из DEVBenSon/FiveM-Plane-Pack, commit db0191619fb3d1cefc225eb5b216a91267ad7740. Текстуры YTD, звуки и системы GTA не перенесены. Разрешение на распространение геометрии не подтверждено: сборка с Су-34 не публикуется; личная сборка выдана владельцу через закрытый черновик релиза.

Исправлены выступавшая нижняя панель носа, укладка колёс, согласование стоек и створок. Основные проверки на 101 положении: [колёса против корпуса, ниш и створок](gear-clearances.json), [стойки/створки и створки/корпус](door-clearances.json) — пересечений не обнаружено; допускаются контакты в зоне шарниров до 5 см. Это проверка дискретных положений, а не доказательство отсутствия всех дефектов между ними.

Ограничения: основные створки выглядят слишком массивными, на части поверхностей заметны тёмные полосы — требуют доработки. Остекление Су-34 фиксированное; вымышленный откидной фонарь не добавлен, входной люк не анимирован. Аэродинамика игровая. Проверки запуска выполняются в Win64/Wine; настоящая Windows 10 x86 недоступна. Архив содержит отдельный Win32 EXE. Старые самолёты и архивы сохранены.
