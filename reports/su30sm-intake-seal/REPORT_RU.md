# Су-30СМ: перекрытие внутренних каналов

Исправлены обе вставки `IntakeDuct_-1` и `IntakeDuct_1`. На проверенных видах серый серп, щели вокруг прежней заглушки и светлый треугольник внутреннего дна больше не просматриваются. Наружная окрашенная рамка сохранена.

## Причина

Прежний генератор (`changes/su30sm-dark-channel/repair.py:25–26`) объединял все замкнутые области сечения, теряя границу собственно воздушной полости, а затем обрезал результат старым прямоугольником. Радиальное приближение дополнительно пропускало некоторые углы. Задняя поверхность находилась при Z=-0,55…-0,75 м; светлое дно впереди неё оставалось открытым.

## Исправление

В `changes/su30sm-intake-seal/repair.py` берётся отдельная внутренняя область, содержащая ось каждого канала. Прямоугольной обрезки нет. Построены 12 действительных сечений между Z=+0,65 и +0,12 м, с сохранением всех измеренных углов. Короткая облицовка глубиной 0,53 м проходит на 5 мм внутри стенок и закрывается задней поверхностью. Это утопленный канал, а не пластина на наружном входе.

Изменён один игровой файл `aircraft/su30sm.dnm`, только два вложенных ресурса:

- `IntakeDuct_-1.srf`;
- `IntakeDuct_1.srf`.

Шасси, створки, все анимационные узлы/STA/родители, исходная геометрия двигателей и внешняя окраска побайтово сохранены. Полезная геометрия двигателя не удалялась — её закрывает внутренняя облицовка. Матовый внутренний материал остался RGB 25/30/33 без свечения. Нормали стенок направлены в канал, задней поверхности — ко входу.

## Реально выполненные проверки

- Запуск Windows x64 OpenGL игры под Wine; **18 пар настоящих кадров до/после** с одинаковыми камерами.
- Фронтальные виды, оба воздухозаборника крупным планом, диагональные виды, боковые направления и виды снизу. Для точного фронтального и нижних ракурсов самолёт также проверен в воздухе на паузе, без наземного ограничения высоты камеры.
- Открыты крупные планы проблемного ракурса, строгого фронтального и нижнего видов; просмотрен сводный лист всех итоговых ракурсов и последовательность обхода камеры. Не утверждается ручной просмотр каждого кадра видео.
- 201 положение шасси: 0 найденных контактов новых вставок с другими проверяемыми узлами, включая корпус и ниши.
- 0 вырожденных/дублирующихся треугольников, 0 неманифолдных рёбер и 0 неожиданных открытых рёбер. Открыт только штатный передний вход, задняя поверхность замкнута. Наложение треугольников задней поверхности — лишь численная погрешность порядка 10⁻¹⁶ м².
- Максимальная ошибка воспроизведения измеренного сечения меньше 10⁻⁸ м². Самосветящихся граней нет.

В просмотренных ракурсах светлая внутренняя геометрия не возвращается при смене камеры. Тонкая окрашенная наружная кромка остаётся видимой, поскольку её форму и окраску менять запрещено. Это результат проверки перечисленных внешних ракурсов, а не обещание для камеры, проникшей внутрь геометрии.
