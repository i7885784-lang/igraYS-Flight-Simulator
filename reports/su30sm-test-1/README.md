# Су-30СМ — отдельная проверка №1

Полная исходная геометрия HappyMexicano7 без децимации, собственные шасси, ниши и створки, ограничение раскрытия сопел, сохранение исходных нормалей в движке. Все 101 положения шасси прошли проверку пересечений; выпуск/уборка и форсаж проверены в игре.

Запуск Windows x86 проверен на настоящем Windows runner: полёт Су-30СМ и две команды шасси, процесс продолжил работу. Итоговый протокол: [STATUS.json](STATUS.json).

- [Полная игра Windows 32-бит](https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/download/untagged-5822aa895db4c29b4d42/YSFlight_Su30SM_Test_1_Game_32bit.zip)
- [HTML, фотографии и три видео](https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/download/untagged-5822aa895db4c29b4d42/YSFlight_Su30SM_Test_1_Sources.zip)
- [Полные исходники, конвертер и исходная модель](https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/download/untagged-5822aa895db4c29b4d42/YSFlight_Su30SM_Test_1_Report.zip)

Архивы находятся в черновике GitHub; для скачивания нужен вход владельца/участника репозитория. Видеофайлы находятся в Report.zip; распаковать его целиком и открыть index.html. HTML в репозитории содержит фотографии; видео доступны в скачиваемом архиве.

Основные ограничения: новый механизм шасси и обтекатели являются игровой адаптацией; PBR эффекты заменены материалами OpenGL 1.x; лётная модель основана на Су-27; облегчённого LOD нет по просьбе пользователя. Старые самолёты сохранены побайтно от production17. CURRENT_VERSION не меняется. Полная поставка остаётся draft с прежним статусом ресурсов Су-34.

Автор исходной модели: [HappyMexicano7](https://sketchfab.com/HappyMexicano7), [модель](https://sketchfab.com/3d-models/85efcbd199844215a171016429a3b4cd), CC BY 4.0. Конвертер и изменения: [changes/aircraft-su30sm-test1](../../changes/aircraft-su30sm-test1).


Одна полная визуальная модель используется на всех дистанциях. Неиспользуемые точки невидимой оболочки столкновений удалены; все 272 физических треугольника точно сохранены. Автоматический демонстрационный полёт отключён в отдельной конфигурации ярлыка Су-30СМ.
