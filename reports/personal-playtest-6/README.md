# Личный тест №6 — исправления Су-27

Изменён **Су-27**: убраны выступающие прямоугольные стенки ниш и лишние детали старых стоек; восстановлена исходная боковая обшивка, устранены наложения поверхностей. Передние створки подогнаны к исходному наружному контуру; колёса, вилки и тяги проходят при уборке внутри корпуса. Сопла получили металлические лепестки и глубину, форсаж связан с двигателями. Отклонение сопел Су-27 не добавлялось.
