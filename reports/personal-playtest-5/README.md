# Личный промежуточный тест №5 — Су-27

У Су-27 заменены огромные створки вокруг воздухозаборников: теперь открываются отдельные узкие крышки, корпус каналов остаётся неподвижным. Стойка, разворот колеса и складные тяги согласованы; колёса убираются внутрь. Исправление посадочного места воздушного тормоза сохранено.

Проверены полный ход механизма и промежуточные положения, реальные нажатия **G** в обе стороны. Просмотрены игровые кадры движения и ракурсы вокруг самолёта. Отдельная пересборка модели совпала побайтно.

**Су-34 пока сохранён из теста №4.** Его новый механизм ещё имеет пересечения и в эту сборку не включён. Прежние проблемы створок и просветов Су-34 не объявлены исправленными. МиГ-29, Су-47, Су-57 и EXE сохранены.
