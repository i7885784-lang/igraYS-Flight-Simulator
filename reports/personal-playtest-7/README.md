# Личный тест №7 — Су-27 и Су-34

**Су-27 сохранён из исправленного теста №6. Су-34 обновлён:** низ двигателей и воздухозаборники неподвижны; шасси выходят через отдельные ниши сбоку корпуса, створки и тандемные тележки согласованы. Подогнаны передние створки, закрыты боковые просветы ниш, убраны дубли и лишние элементы донора, доработаны сопла. МиГ-29, Су-47 и Су-57 сохранены.

[Личный черновик игры и полных исходников](https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/tag/untagged-47828a88991652e71793). ZIP собирается; подтверждённые ссылки и суммы появятся в STATUS.json. Нужен вход в аккаунт владельца GitHub. Не публиковать: права Су-34 не выяснены.

Проверены реальные клавиши G/B, крайние положения рулей и ПГО, форсаж, промежуточные положения механизма и игровые ракурсы. Видео просмотрены. Геометрический проход переднего и основных шасси проверен в 401 положении, включая интерполяцию. [Протокол](CHECKS.json), [конвертер и авторство](../../changes/su34-personal-test7/).

Поставка — самостоятельный Windows 32-bit ZIP; игровой запуск проверялся **Win64/Wine**, а не на настоящей Windows 10 x86. Кинематика остаётся игровой адаптацией: полная заводская последовательность по видео не подтверждена, видеохостинги возвращали HTTP 403. Не заявляю отсутствие любых возможных дефектов; это версия для твоей проверки. Утверждённая основа проекта и старые архивы не менялись.
