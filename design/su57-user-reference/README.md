Новый визуальный эскиз создан по двум присланным фотографиям, без использования предыдущих сгенерированных форм. Сине-белая окраска взята с первого фото, второе использовано для уточнения геометрии. Один крупный ракурс, чтобы не смешивать несовместимые проекции.

Это сгенерированный визуальный ориентир, а не точный измерительный чертёж. При создании модели силуэт и размеры деталей сверяются с исходными фотографиями. Игра пока не менялась.
