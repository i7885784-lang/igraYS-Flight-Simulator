# Су-30СМ: ручной режим высоких углов атаки

База VectorNozzles e869...; геометрия, DAT, окраска, шасси и сопла сохранены. Режим по умолчанию выключен. Ctrl+L включает управление угловой скоростью тангажа вместо обычного задания угла атаки до23°. Включение только в воздухе ниже720км/ч; возврат обычного ограничителя только при |AOA|<25°, чтобы избежать резкого скачка восстановления.

Это новая игровая аппроксимация ручного снятия ограничителя, не заводская СДУ Су-30СМ и не гарантированная безопасность любого манёвра. Целевая скорость вращения65°/с, ограничение ускорения140°/с², плавное ограничение положительной команды105…125°AOA и отрицательной30…45°. Нейтральная ручка оставляет восстанавливающее действие. Доступная аэродинамическая эффективность убывает с квадратом скорости; прежний реальный вектор тяги и его момент рассчитываются отдельно. Автопилотные G/AOA/pitch-регуляторы, управление на земле и другие самолёты используют прежний код. Силы, положение и ориентация интегрируются обычным движком; сценария заданных положений для кобры нет.

Воспроизведение: к неизменённой полной копии движка VectorNozzles применить `python patch.py ENGINE`. Патч отказывается повторно накладывать те же строки; перед записью разрывает hardlink. Компиляция стандартным `../su30sm-nozzle-vector/build.sh ENGINE 64 BUILD`. Начальный VectorNozzles source создаётся из защищённых SHA исходных частей предыдущего изменения и его patch_engine.py. Полные предыдущие исходники сохранены на GitHub release su30sm-nozzle-vectoring-20261115.

Проверка `g++ -std=c++11 -O2 test.cpp -o test && ./test` проверяет ограничение ускорения, знаки, нейтральное восстановление, эффективность на малой скорости, обычный режим на большой скорости и модельный отклик без движения траектории. Последняя проверка не заменяет настоящий игровой полёт. Успешную кобру следует подтверждать реальным AOA, скоростью, высотой/траекторией и восстановлением, а не одним тангажом90°.
