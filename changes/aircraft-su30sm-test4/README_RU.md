# Су-30СМ, тест 4 — сверка по присланным схемам

Продолжение проверенного теста3. Пользователь предоставил цветовой лист HobbyMaster HA9506 и размерный общий вид Су-30СМ; затем отдельно разрешил менять нос. Сверка учитывает размерные стрелки (14,7м размах; 5,57м база; 4,10м колея; 6,36м высота). В нечёткой таблице есть противоречивые записи: их не используем как точные размеры. Происхождение листа как заводского документа не подтверждено.

Носовая стойка перенесена из ошибочного переднего положения назад, основные стойки выставлены по колее. Ниши/створки создаются заново из исходной геометрии, поэтому старой передней дырки не остаётся. Отдельный тонкий носовой приёмник сохраняет общую длину; серо-голубая окраска собственная, по мотивам цветового листа. Нормали сглаживания отсутствуют: границы цветовых пятен делятся внутри существующих плоских граней и не меняют поверхность.

Воспроизведение: установить requirements.txt, извлечь Game3 в runtime/, положить исходный GLB в source/su-30sm.glb, выполнить python pipeline.py. Полный GLB и соответствующий неизменённый движок уже включены в SourcesZIP, см. CURRENT_ENGINE.txt. Исполняемые файлы и библиотеки взяты побайтно из проверенного Game3, калибровка сопел совпадает с его движком. Новый C++ не добавлялся.

pipeline.py повторяет convert → identical_nozzles → shape_stage → gear → flat_shading → finish → baseline → revise → style_finish. Нельзя запускать shape_stage повторно над уже расширенными крыльями. Начинать полный цикл с convert.py. В SourcesZIP сохранены предыдущие версии, лицензии и уведомление HappyMexicano7 (CC BY4.0). Условная кинематика/интерьер и динамика Су27 не выдаются за заводскую модель.

Ctrl+Shift+F9 включает диагностические цвета отдельных деталей; повторное нажатие возвращает обычную окраску. Это не потеря материалов.

Проверка check_fixes.py необязательна для конвертации; дополнительно требует python-fcl. measure.py проверяет размеры и совпадение физических опорных точек с видимыми осями колёс.
