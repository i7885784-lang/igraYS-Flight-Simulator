Су-30СМ: Ctrl+Shift+L открывает небольшую панель справа. F7/F8 уменьшают/увеличивают положительный предел AOA на5° в диапазоне30–110°. F9 возвращает65°. Ctrl+L отдельно переключает манёвренный режим. Настройка действует только в этом режиме, хранится до нового полёта; обычный режим/стабилизация/геометрия прежние. Это игровой параметр, не заводская характеристика. Сборка: python changes/su30sm-high-alpha/build_candidate.py 32 (или64). Проверка: g++ -std=c++11 -O2 changes/su30sm-high-alpha/test.cpp -o /tmp/su30-test && /tmp/su30-test. Нативная проверка: python changes/su30sm-aoa-panel/check_native.py 32/64.
