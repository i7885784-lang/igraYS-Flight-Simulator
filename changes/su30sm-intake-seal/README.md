# Су-30СМ: точное перекрытие внутренних воздухозаборников

База — последний BaySeams ea3d9ced, результат8404cc19. Только IntakeDuct_-1/1.srf; все остальные ресурсы и все узлы/анимации буквально прежние. Действительные внутренние воздушные области вместо объединённого внешнего контура, без старой прямоугольной обрезки; 12секций/53см закрытой облицовки,5мм внутрь стенок. Никакая исходная геометрия двигателя не удалялась.

Точное воспроизведение: baseline/su30sm.dnm с SHAea3d9ced…, `pip install -r requirements.txt`, `python build.py`. Строгий сборщик проверяет базу/редактируемыеSRF/итогSHA. Алгоритм построения — repair.py. После повторной триангуляции нужны проверки check.py/validate.py и игра.

Проверки: requirements-validation.txt, 201положение0контактов;нормали/полнаязадняяповерхность/нулевыенепредусмотренныеоткрытыерёбра/0вырожденных/дублей. Реальные matchedPNG18пар+обход: reports/su30sm-intake-seal. Повышенное разрешение было отклонено как некорректная конфигурация окна; такие кадры в отчёт не включены. Поставляются только подлинные рабочие 1024x768 кадры.

Модель не меняет EXE или архитектуру игры. Полные исходники прежнего движка/GLB/лицензии остаются в истории и прежних FullSources. Новая папка содержит только воспроизводимые исходники узкой правки.
