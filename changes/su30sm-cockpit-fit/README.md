# Су-30СМ: подгонка интерьера кабины

Основа — последний принятый LocalDefects DD9 и его отдельная кабинная модель59e8226d. Меняется только Su30Interior.srf в обоих DNM. Внешняя обшивка, неподвижное лобовое стекло Fuselage_0_6 (alpha42), подвижный фонарь, кресла, приборы, шасси и все узлы сохраняются. Коробки панели и её козырёк объединены в замкнутый объём с исходными цветами; передние концы консолей, пола и торцевая стенка подогнаны к реальным сечениям. Задняя неполная стенка заменена замкнутым внутренним объёмом с полкой и боковинами, позади кресла. Его верх ограничен корпусом и траекторией фонаря. Нет случайных наружных накладок и перекраски.

Исторический источник ошибочных размеров: changes/aircraft-su30sm-test4/model-source/revise.py:41–50. Старый pipeline целиком не запускается: это откатило бы поздние принятые исправления. Новый локальный генератор читает защищённую DD9 и меняет один SRF. Envelope получает настоящие сечения из сохранённых мешей; ограничения берутся по диапазону высот/сечений, а не по единственной пробе. Триангуляция вогнутых торцов — Triangle PSLG; совпадающие рёбра ступенчатых профилей соединяются разбиением существующих граней.

Установить зависимости из changes/su30sm-local-skin/requirements.txt. Из корня SourcesZIP:

```sh
python changes/su30sm-cockpit-fit/repair.py --baseline baseline/su30sm.dnm --cockpit-baseline baseline/su30smcockpit.dnm --output rebuilt
python changes/su30sm-cockpit-fit/check.py baseline/su30sm.dnm baseline/su30smcockpit.dnm rebuilt quality.json
python changes/su30sm-cockpit-fit/check_canopy.py rebuilt canopy.json
```

Сравнить SHA с dist/su30sm-cockpit-fit/metadata.json. Только один SRF-патч используется одинаково в наружной и кабинной DNM. freeze.py BASE CPBASE GENERATED OUTDIR создаёт этот патч; apply.py восстанавливает оба файла с проверкой их SHA. Windows-подготовка и упаковщик берут настоящие отдельные предыдущие x86/x64 ZIP с проверкой SHA/PE/CRC, сохраняют все прочие ресурсы и обе модели для отката. REQUIRE_NATIVE_CHECKS=1 требует свежих протоколов Windows с обоими совпадающими DNM и EXE.

Полные соответствующие неизменённые исходники движка и история лицензий сохранены в предыдущем FullSources (указатель включён в поставку). Новые ограничения и реальные кадры — reports/su30sm-cockpit-fit/REPORT_RU.md. Внутренний рабочий контекст в публичную поставку не входит.
