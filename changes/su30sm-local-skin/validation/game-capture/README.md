Historical capture harness used for this repair. accepted_capture.sh records the exact tested camera parameters and environment paths; adapt paths to your Wine setup. It depends on the existing project Wine environment, Xvfb/XTest and resize_capture.exe helper, and the x64 EXE diagnostic commands. This harness changes only temporary fixture/user files, never the shipped runtime. The before-static run used the same CAPS with the baseline runtime. This is a Linux/Wine harness, not a native Windows test.
