## Воспроизведение

Python 3.12, зависимости requirements.txt; g++ (локальные проверки); CMake, Ninja, g++-mingw-w64-{i686,x86-64}-posix. На Ubuntu: `python prepare.py 32` или `python prepare.py 64` из этой папки. Каждая архитектура собирается в отдельном checkout. Исходные части из dist/su30sm-nozzle-vector проверяются по SHA256; accepted game ZIP используется только как источник неизменённых ресурсов и исходных моделей. Нужен доступ к GitHub для его загрузки.

`patch_engine.py ENGINE` применять к неизменённой исходной копии engine: скрипт отказывается повторно патчить текст. `model.py --baseline baseline/su30sm.dnm --output generated/su30sm.dnm` строит новую модель. Исходные 162 SRF, старые STA/CNT/PAX и cockpit сохраняются. Два новых родителя поворачивают существующие сопла, внутренние горловины и струи. CLA284/285 связывают радиус горловины с раскрытием.

`g++ -std=c++11 -O2 test_nozzles.cpp -o test_nozzles && ./test_nozzles` проверяет исполнительный алгоритм, независимые аналитические силы и моменты, демпфирование, скорость, пределы и режимы двигателя. `python check_model.py BASE MODEL RESULT` требует дополнительно trimesh и проверяет сохранность исходных мешей, замкнутость новых уплотнений и направление поворота против расчётной силы.

Windows CI отдельно запускает настоящие PE32 и PE32+ EXE. x64 содержит прежние validation-команды и телеметрию: статические NOZZLEPOSE не выдаются за управление в полёте. x86 проверяется обычным управлением, без этих команд. Публикация допускается только с passed native-results для обоих точных EXE/модели.

Для отката нужны СРАЗУ прежний EXE и main DNM из rollback-vector-nozzles, плюс паспорт и файл источников, если он был заменён. Только откат модели оставит новые силы при неподвижных соплах. Принятые полные CockpitFit ZIP сохранены на GitHub.

## Границы реализма

Это согласованная игровая аппроксимация, не заводская СДУ/FADEC. Для АЛ-31ФП производитель HAL указывает ±15°. Одноосевые наклонённые сопла семейства Су-30 и связанное управление креном/рысканием описаны Vinayagam & Sinha, DOI 10.1177/0954410013485697. Наклон 32°, скорости приводов, коэффициенты смешивания, RPM-прокси, расписание площади и моменты инерции не следует выдавать за проверенные заводские таблицы Су-30СМ. Разностная команда создаёт одновременно крен и рыскание; чистого независимого управления этими осями двумя соплами нет. Остальные рули и исходная аэродинамическая стабилизация сохраняются.

Предыдущий полный исходный GLB/движок/история и атрибуция: https://github.com/i7885784-lang/igraYS-Flight-Simulator/releases/download/su30sm-local-skin-20261111/Su30SM_LocalSkin_FullSources.zip . Текущий FullSources содержит соответствующий изменённый код и библиотеки, baseline/generated модели, генератор, проверки, инструкции и лицензии.
