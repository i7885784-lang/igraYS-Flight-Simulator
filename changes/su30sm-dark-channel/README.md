# Су-30СМ: затемнённые внутренние каналы, отчёт без сборки

Новый запрос разрешает внутреннюю тёмную поверхность/заглушку и требует подробные реальные скриншоты/видео, без ссылки на сборку. Отдельная копия от IntakeArtifacts6fd0f298; stableCURRENT5 и предыдущая база сохранены.

Изменены только IntakeDuct_-1/1.srf: прежние искусственные прямоугольные стенки и видимые28-лопаточные диски заменены матовыми вогнутыми внутренними экранами. Исходные Fuselage/GearWell и все прочие ресурсы самолёта буквально прежние. Ни одной исходной поверхности корпуса/механизмов не удалено. Все узлы, STA, родители и оси точные. Окраска внешней обшивки прежняя. Внутренний материал новых вставок RGB25/30/33, без самосвечения.

Форма взята из настоящего сечения F4 при Z=-0.55м: 8мм внутрь корпуса, ограничена существующей проекцией входа, 48направлений. Экран уходит кZ=-0.75м, глубина0.20м. Это скрывающий визуальный экран по явному разрешению пользователя. Он не выдаётся за восстановленную заводскую конструкцию двигателя. Более глубокая проба пересекала убирающиеся колёса, она отклонена; окончательная проверка201поз даёт0контактов с движущимся шасси, корпусом и облицовками.

Точное повторение: baseline/su30sm.dnm должен иметь SHA6fd0f298… (предыдущая рабочая копия). `pip install -r requirements.txt`, `python build.py` собирает точный проверенный ресурс из редактируемыхSRF. Полный алгоритм `python repair.py` также приложен. Проверки: requirements-validation.txt, `check_motion.py`, `validate.py`. Исходники полного прежнего движка/GLB/лицензии остаются в ранее сохранённом проекте; в этой задаче они не менялись.

Главный результат — reports/su30sm-dark-channel/REPORT_RU.md, index.html, оригинальные PNG и MP4. Новая сборка игры не публикуется по текущему запросу. Все изображения должны быть реальными игровыми кадрами окончательного SHA, не ранних проб. Геометрия заморожена для визуальной проверки.
