# Исходные изменения теста Су-57 №1

`generate_su57.py` создаёт собственную геометрию и DNM-иерархию Су-57; `collision_su57.py` — упрощённую форму столкновений; `native.patch` — изменения C++ относительно самолётного теста №6. Это добавление к YSFlight, а не полный исходный код всего симулятора.

Для генератора нужны Python, NumPy, SciPy и Pillow. Запуск: `python generate_su57.py` из этой папки. Выходные файлы создаются в `runtime/aircraft/`. `baseline_su27.dat` нужен только как шаблон игровых параметров; геометрия Су-27 не используется.

Сначала проверять силуэт по фотографиям пользователя, затем крайние и промежуточные положения механизмов. Не возвращать флаг B обычной обшивке; не делать ниши шасси поверх неразрезанного корпуса; не копировать створки с внутренних пересекающихся поверхностей; не наклонять кили внутрь; не добавлять тормозной щиток Су-27.

Проверки, реальные кадры и ограничения: [отчёт](../../reports/su57-test-1/REPORT.md).
