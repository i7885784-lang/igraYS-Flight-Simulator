# Личный самолётный тест №9

Исправления от полной сборки №8: объёмные основные шины Су‑34 с исходными наружными дисками и согласованной уборкой; внутреннее закрытие ниш МиГ‑29; утопленная облицовка воздухозаборников Су‑34 с сохранением передней наружной обшивки; собственные струи и детали сопел пяти самолётов. Добавлены три недостающие кнопки быстрого запуска.

Полная геометрия Су‑34 и готовая игра остаются в закрытом черновике релиза до выяснения прав. В этом каталоге нет YFT/DNM, текстур или звуков GTA. Авторы и прежние лицензии сохранены.

Пересборка из полного архива исходников:

```sh
python -m pip install -r test9/requirements.txt
python test9/build.py
```

Сохраните рядом `test7-su34/`: из его исходного YFT прежний конвертер восстанавливает геометрию для сверки. `test9/baseline/` содержит пять DNM поставленной сборки №8. Оптимизация при пересборке не требуется: принятые параметры и путь шарниров сохранены в JSON. Проверенные SHA-256 находятся в `expected.json`.

Движок: [BUILD_ENGINE.md](BUILD_ENGINE.md). Изменения `native.patch` применяются к полному `engine/` из архива №8; контрольные суммы трёх изменённых файлов — `engine-files.json`.

Проверки игры выполнены в Win64/Wine. Поставляемый EXE — Win32 GUI, без проверочных команд. Прямой запуск на Windows 10 x86 в этой среде не выполнен.
