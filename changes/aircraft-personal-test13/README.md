# Тест №13 — просвет основной ниши Су-27

Сохраняет все исходные поверхности и узлы/анимации №12, добавляет две собственные внутренние стенки ConformalMainBayLinerL/R. Контур рассчитан по исходной обшивке Су-27 и объёму перемещения колёс/стоек/створок. Ограничен верхней/нижней исходной оболочкой, наружный короб не добавляется. Исправление одинаково применяется к обоим бортам.

Полные входные файлы в закрытом архиве исходников: test13/baseline/su27.dnm, test13/upstream/Su-27.ac, test13/model-source/. `pip install -r test13/requirements.txt`; `python test13/fix_su27.py`; `python test13/audit.py`. Последняя команда проверяет 28 узлов класса210 против двух новых стенок на401 положении, с интерполяцией ориентации как в движке. Это проверка пересечений с новыми стенками, не гарантия отсутствия всех возможных ошибок модели.

Движок, исправление тень/струя №12 и другие самолёты неизменны. Исходное авторство Су-27/FGUK/FGMEMBERS и GPL сохранены; новая адаптация собственная. Полная сборка остаётся закрытой из-за невыясненных прав Су-34. [Отчёт](../../reports/personal-playtest-13/README.md).
