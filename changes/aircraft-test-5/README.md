# Тест №5: незавершённые исправления

Отдельная рабочая копия от выданного теста №4. Архивы №4 и закрытый Су-34 не изменены.

Пока исправлена только посадка тормозного щитка Су-27: возвращён исходный контур панели вместо масштабов длины 0.71 и ширины 1.18; сохранены штатное вращение и компактный привод. Patch применяется к model-source/corrections.py из [исходников теста №4](https://raw.githubusercontent.com/i7885784-lang/igraYS-Flight-Simulator/5e5aa0a/downloads/YSFlight_Playtest_4_Sources.zip). Скрипт проверяет сохранение остальных узлов и состояний. Нужны зависимости исходников.

Ниши и створки Су-27/Су-34 ещё не исправлены по реальным видео. Не выдавать эту правку за готовую следующую сборку. Источники геометрии и лицензии сохраняются, код адаптации GPL-3.0. Геометрия Су-34 сюда не включена.
