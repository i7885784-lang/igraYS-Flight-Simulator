# Личный тест №8 — исходники изменений

Основа — полная личная версия №7, а не старые модели. Старые архивы сохранены.
Скопировать пять DNМ из её `aircraft/` в `baseline/`: `su27.dnm`, `mig29.dnm`,
`su34.dnm`, `su47.dnm`, `su57.dnm`. Установить `requirements.txt`, выполнить
`python build.py`. Получатся десять файлов в `runtime/aircraft/`.
Контрольные суммы исходной основы и проверенных результатов — `expected.json`.
Файл `mig-path.json` содержит проверенную траекторию; оптимизация при сборке не запускается.

`native.patch` применяется к `engine/` из соответствующего архива исходников №7.
Он добавляет Ctrl+Shift+F9, плавное раскрытие сопел и согласование впускных створок.
В комплекте источников №8 лежит уже применённый полный снимок движка. `bin/` содержит
только новый Win32 GUI EXE; его нужно использовать вместе с новыми DNM. Старую
игру не перезаписывать: скачать полную сборку №8 и распаковать в новую папку.

По умолчанию диагностика выключена. Нажатие Ctrl+Shift+F9 включает цвета отдельных
деталей самолёта игрока, повторное возвращает обычную окраску. Удержание не вызывает
повторных переключений. Геометрия, освещение, прозрачность и механизмы сохраняются.
Цвета соседних деталей могут быть близкими; это осмотр отдельных модельных узлов,
а не режим рентгена или раскраска каждого треугольника.

Сведения об источниках и ограничениях — [NOTICE.txt](NOTICE.txt).
Су-34/YFT/DNM и приватная исходная основа сюда не включены.
