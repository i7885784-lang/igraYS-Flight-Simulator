# Aircraft fixes test 2

Отдельная копия от Fighters FG Test 1. Старые архивы не заменены.
[Короткий отчёт](../../reports/aircraft-fixes-test-2/REPORT.md).

Модели: `model-source/build_model.py` — Су-27/МиГ-29 (GPL-2.0),
`su57-source/build_model.py` — интегрированная поздняя ревизия Су-57 (GPL-3.0).
Лицензии, исходные AC3D и сведения об авторах находятся в этих папках.
Python 3, NumPy/SciPy/Pillow; зависимости в `requirements.txt`.
Конвертеры выводят файлы в собственные `runtime/aircraft/`.
Положить 15 полученных файлов в новую полную игру; сохранить Су-47.
В aircraft.lst использовать su27_coarse.dnm и остальные нынешние записи.

Шасси: corrections.py, фиксированные опоры, отдельный поворот колёс,
21 существующее положение анимации, створки открыты до движения стоек.
Геометрия не скрывается, чтобы спрятать выступающие части.
Замкнутые ниши/створки содержат все убранные узлы; проверяется также
проход колёс через проёмы в промежуточных состояниях.
Щиток Су-27 укорочен из исходного контура; привод рассчитан по двум опорам.
Входные защитные экраны МиГ-29 включаются только на земле ниже 60 м/с,
а верхние жалюзи следуют тому же состоянию. Полётные каналы открыты.

native.patch — разница от Fighters FG Test 1; SHA указаны в engine-hashes.json.
Полный архив исходников уже содержит патч, повторно не накладывать.
Производственная сборка MinGW i686 POSIX + CMake Release/Ninja:
точные команды и флаги унаследованы от changes/fighters-fg-test-1/README.md.
Для лаборатории существует отдельный Win64 EXE с V861_VALIDATION.
Проверочный resize_window.c только меняет размер окна Wine для съёмки;
в игровой ZIP этот вспомогательный EXE не включается.
check_game.py: один общий осмотр и целевые gear/brake/canopy/ground.
Настоящие клавиши записываются через XTest, фото — окно YSFlight.
Нужны env.sh, Wine, Xvfb :99, FFmpeg и полный runtime рядом со сценарием.
validate.py объединяет проверки геометрии и сохранения Су-47.

Подробная заводская документация недоступна: повторы запросов и альтернативные
веб-сайты возвращали HTTP 403. Доступны закреплённые авторские репозитории
FlightGear. Заводская точность выбранных размеров и гидравлики не заявляется.
Фотографии и видео — Win64/Wine; native Windows 10 x86 здесь не проверен.
