# Су-27 — изменения личного теста №5

Здесь только новые скрипты и параметры. Полная самостоятельная папка конвертера с `working-base`, AC3D-источником, зависимостями и лицензиями включена в закрытый ZIP исходников. В ней: `pip install -r requirements.txt`, затем `python make_upper_bay27.py`; выход — `runtime/aircraft`.

`build_draft.py` восстанавливает входы из сохранённых архивов теста №4, применяет опубликованную правку тормоза и новые механизмы. Он требует побайтного совпадения с проверенной локальной моделью. EXE и остальные самолёты сохраняются. Готовая игра с прежним Су-34 загружается только в owner-only черновик, не в публичные downloads.

Створки выделены из исходного GPL-2.0 Su-27.ac; окраска наша. Сохранены FGUK и исходные уведомления. Кинематика — игровая адаптация, не заводская документация. Доработаны колёса, тормозной блок, цилиндр и шарниры; детали при уборке не скрываются.
