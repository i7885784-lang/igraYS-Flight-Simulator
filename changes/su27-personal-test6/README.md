# Су-27: личный тест №6

Исправления поверх сохранённого личного теста №5. Геометрия FGMEMBERS/FGUK, GPL-2.0; авторство и исходники сохранены. Чужие текстуры и звуки не добавлены.

Для воспроизведения установить `requirements.txt`, создать `baseline/su27.dnm` из игры теста №5 и пустую `runtime/aircraft`, затем выполнить `python repair_su27.py` и `python nozzles.py`. `expected.json` содержит проверенные SHA-256. Полный самостоятельный набор этих исходников, исходные материалы предыдущих версий и базовая модель включаются в приватный архив исходников.

`build_draft.py` воспроизводит проверенные модели и добавляет их в полную игру №5. Проверяет остальные самолёты побайтно, повторно скачивает ZIP и проверяет запрет анонимного скачивания. Сборка с неизменённым Су-34 остаётся только черновиком.
