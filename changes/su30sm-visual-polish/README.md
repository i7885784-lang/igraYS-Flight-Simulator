# Су-30СМ — точечная визуальная доводка

База — проверенная GearBays08e5e8fc, отдельная копия; стабильная5 и предыдущие архивы сохраняются. Запрос6ноября2026 разрешает точечные правки двигателей, зазоров, фонаря/тормоза, запрещает изменение общей окраски и разрушение анимации.

`repair.py`:30мм вместо70мм сдвига дверей, те же углы/тайминг, укороченные вилки; фонарь43°вместо55°, тормоз50°вместо60°, согласованный привод; два подтверждённых внутренних конусных пика в F13 утоплены за горловины и матированы; удалены4 наружных дублирующих грани стенок каждого IntakeDuct, физические стенки/вентилятор сохранены. Углы — визуальная аппроксимация по пользовательским фото, не заводские сертифицированные пределы.

Колёса, стойки, внутренние крышки MainWheelBayShutter, лепестки сопел, форсаж, физика/управление/EXE/остальные самолёты точные прежние. Окраска внешних поверхностей прежняя. Сглаживание не включалось. Позиции/иерархия/оси исходных узлов сохранены. Новых узлов нет. В отдельном cockpitDNM согласованы только2состояния фонаря.

Точная поставка: в полном SourcesZIP уже есть baseline/двеDNM. Установить requirements.txt, выполнить `python build.py`: собирает проверенные SRF/узлы из manifest.json и проверяет обаSHA. Полный алгоритм: `python repair.py`; исходные геометрические операции редактируемы, после новых правок нужна новая проверка.

Проверка: requirements-validation.txt, `final_motion.py`, `validate.py`. Матрица201поз не доказывает отсутствие любых пересечений всего самолёта. Старый контакт основных колёс с IntakeDuct остаётся; старое фасеточное освещение местами тоже. См. REPORT_RU.md/acceptance.json/STATUS.json в reports/su30sm-visual-polish.
