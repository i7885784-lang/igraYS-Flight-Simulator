# Тест №14 — стык задней части основной ниши Су-34

Добавлены две собственные внутренние перегородки Su34RearBayInnerWallL/R между задней частью основных ниш и мотогондолами. Их положение закрывает сквозной вид с задних боковых ракурсов, не удаляя штатные кромки, крепления или створки. Все прежние поверхности, узлы и состояния Су-34 сохранены; движок и остальные самолёты точно №13. Внешняя геометрия воздухозаборников не переделывается.

В полном архиве исходников: test14/baseline/su34.dnm, test14/baseline/uncut-su34.srf и test14/model-source/. `pip install -r test14/requirements.txt`; `python test14/fix_su34.py`; `python test14/audit.py`; `python test14/check_preservation.py`. Проверяются401 промежуточное положение всех узлов класса210 против новых перегородок, неизменность прежней геометрии/анимации и отсутствие пересечений перегородок с внутренними каналами и исходными компрессорами. Это проверка новых деталей, не гарантия отсутствия любых ошибок модели.

Сравнение игрового участка: check_rear.py с теми же камерами до/после (45° и300°, высота камеры на уровне стыка), контрольные области verify_gap.py. Скриншоты и видео Win64/Wine; Win32 EXE неизменный из №13. Полная сборка остаётся закрытой до выяснения прав Су-34; источник fantazer_rnd / DEVBenSon/FiveM-Plane-Pack и исходная геометрия сохранены, новых чужих текстур/звуков нет.
