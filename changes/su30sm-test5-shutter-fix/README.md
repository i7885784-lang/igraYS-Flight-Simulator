## Повторная сборка

Python 3.12, `pip install -r requirements.txt`.
В каталоге этой правки: поместить исходную DNM в `baseline/su30sm.dnm`, скопировать `source-data/support-*.srf` в `baseline/`, создать `runtime/aircraft/`, выполнить `python refine.py`.
В Sources ZIP исходная DNM уже сохранена в baseline. Проверка строго ограничивает изменения двумя SRF и сохраняет записи узлов. Для повторного извлечения опорной кожи: `python extract_support.py /path/to/sources/su30sm-test4/baseline/su30sm.dnm`; результат извлекается в baseline. Не подставлять поверх него готовую интерполированную крышку №4.

Проверки: `pip install -r requirements-validation.txt`, затем `python validate.py`, `python selfcheck.py`, `python classify_contacts.py`.
