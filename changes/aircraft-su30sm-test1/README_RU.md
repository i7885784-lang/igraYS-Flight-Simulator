# Су-30СМ: отдельная проверка №1

Исходная модель пользователя: SU-30SM, HappyMexicano7, CC BY 4.0.
https://sketchfab.com/3d-models/85efcbd199844215a171016429a3b4cd

Полная геометрия: 418250 треугольников, 94 меша. Децимации нет. Одинаковый полный DNM используется и для дальнего варианта по просьбе пользователя. Добавлены собственные шасси, ниши, створки, пламя и ограничение исходной анимации сопел. Динамика основана на Су-27; точной симуляцией Су-30СМ эта версия не является.

Конвертер читает GLB, сохраняет исходные вершины/грани и нормали, преобразует цветовые коэффициенты в RGB. Нижняя обшивка разрезана на границы ниш и перенесена на створки; исходная площадь при разрезании сохраняется. Добавлены наружные обтекатели ниш. Полная исходная сцена GLB приложена к архиву исходников. PBR-эффекты и текстурные эффекты стекла не эквивалентны glTF: использовано прозрачное окрашенное стекло YSFlight. Новые шасси не взяты из исходной модели: их там не было.

В архиве Sources находятся папка su30sm-test1 с полным изменённым движком и библиотеками, исходный GLB, лицензии и конвертер; history/YSFlight_Test_17_Sources.zip сохраняет соответствующие исходники предыдущей игры.

## Воспроизведение модели

Распаковать Sources. В папке su30sm-test1:

```sh
python -m pip install -r requirements.txt
python model-source/convert.py
python model-source/gear.py
POSES=101 python audit_gears.py
```

Результат: runtime/aircraft/su30sm.dnm и su30sm_coarse.dnm. DAT, регистрация и запуск находятся в runtime-template; скопировать их вместе с моделями в полную игровую сборку.

Сборка движка в Linux: CMake, Ninja, MinGW-w64 POSIX i686/x86_64; `bash build_engine.sh 32`. Полные исходники находятся в engine/YSFLIGHT и engine/public, переносимые файлы toolchain — в engine/. Диагностическая 64-битная сборка: `bash build_engine.sh 64`. Патчи к прежнему снимку движка отдельно в engine-patches.

Аудит проверяет колёса, стойки и створки против корпуса и ниш во всех 101 ключевом положении. Контакты шарниров, закрытых сопряжений и общего шва передних створок до их поворота учитываются отдельно. Это проверка геометрии, а не гарантия отсутствия любых ошибок во всей игре. Протокол и реальные фото/видео находятся в отчёте. Старые самолёты сверяются побайтно с production17.

Полная поставка сохраняется как GitHub draft из-за прежнего статуса ресурсов Су-34. CURRENT_VERSION проекта не меняется.
