# Конвертер Су-34 для личного тестирования

Здесь только наш Python-конвертер, настройки, уведомления и сценарий запуска. Геометрия YFT/DNM, текстуры и сборка игры с Су-34 **не публикуются**. Код адаптации распространяется по GPL-3.0; эта лицензия не распространяется автоматически на исходную геометрию самолёта. Её разрешение на распространение/продажу не установлено. Автор в источнике — fantazer_rnd.

Исходник фиксирован коммитом и SHA-256 в provenance.json. Конвертер читает только геометрию su34_hi.yft и фрагменты колёс; YTD не нужен. Локально: установить model-source/requirements.txt, поместить YFT в upstream/, выполнить python model-source/build_model.py. Уведомления — model-source/NOTICE.txt и CODEWALKER_LAYOUT_NOTICE.txt.

GitHub Actions собирает личную копию из этих исходников и уже проверенной публичной основы. Она загружается **только в черновик релиза**, видимый владельцу и пользователям с правом записи. До загрузки проверяется закрытость черновика, после — скачивание с авторизацией и HTTP 404 без неё. Публикация релиза запрещена до выяснения прав. Никаких публичных Actions artifacts с моделью не создаётся.
