# Тест №12 — регрессия перекрытия струи тенью

Основа — полная №11; геометрия самолётов не менялась. Исправление в `YSFLIGHT/src/core/fssimulation.cpp`: при включённой прозрачности непрозрачные самолёты, поле и наземная тень рисуются перед прозрачными самолётами/эффектами. Проход тени не закрашивает уже смешанную струю. Это применяется ко всем самолётам, не к списку названий. При старой настройке TRSPLATER FALSE используется тот же корректный порядок для прозрачных объектов. Глубина корпуса остаётся включённой, повторного рисования струи поверх корпуса нет.

Проверки `check_shadow_overlap.py`: реальный разогрев двигателя клавишами, пауза и одинаковая поза 3 м над аэродромом AOMORI; три камеры с перекрытием тени и струи. Пять самолётов, до/после. Дополнительно Су-34 с TRSPLATER FALSE. Это диагностический запуск Win64/Wine и Xvfb :99, нужен Pillow и вспомогательный resize_window.exe; исходник утилиты приложен. GAME_RUNTIME указывает распакованную игру, GAME_EXE — диагностический Win64 EXE. Сборка движка как test10/BUILD_ENGINE.md из полного архива, для диагностических команд включить V861_VALIDATION только у Win64.

После парных запусков: `python verify_overlap.py /path/to/lab`. Нужны Pillow/numpy. Проверка требует восстановления свечения на бывших чёрных пикселях тени минимум на двух ракурсах каждой машины, сохранения тени вне струи и неизменности видимой синей обшивки. Отдельно сравнивает старую настройку порядка прозрачности. Исходные полные кадры и результаты в отчёте.

Win32 GUI собран, игровые проверки Win64/Wine; Windows x86 напрямую не запускался. Полная игра/геометрия Су-34 только в закрытом черновике до выяснения прав. Старые исходники и авторство сохранены.
