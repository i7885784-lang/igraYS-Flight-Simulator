# Личный тест №10 — струя и выходное сечение

Струя обоих двигателей пяти самолётов теперь следует за реальным раскрытием сопла: ширина по двум осям, положение центра и начало у выходной кромки. У Су-57 преобразование остаётся в системе отклоняемого сопла. Остальные поверхности и все узлы анимации сохранены из полной №9.

Из полного архива исходников:

```sh
python -m pip install -r test10/requirements.txt
python test10/build.py
python test10/validate.py
```

Для последней команды нужен `g++`. Конвертер читает пять DNM №9 из `baseline/`, измеряет движущиеся внутренние кромки и одновременно создаёт модели и `fsexhaustprofile.h`. При изменениях геометрии сопел обновляйте этот заголовок в `engine/YSFLIGHT/src/vehicle/`, чтобы сетка и движок оставались согласованы. Хеши фиксируются в `expected.json`; оптимизаторы при пересборке не используются.

`validate.py` проверяет коэффициенты скомпилированного C++ по реальной геометрии в промежуточных положениях, положение начала струи, её нахождение внутри выходного сечения и неизменность остальных поверхностей. Это геометрическая визуализация, не CFD.

[Сборка движка](BUILD_ENGINE.md). Новый патч применяется к полному `engine/` из исходников №9. Нужные авторам уведомления и первичные исходники сохранены в полной цепочке предыдущих конвертеров.

Готовая игра с Су-34 остаётся в закрытом черновике до выяснения прав. В этом публичном каталоге нет YFT/DNM, чужих текстур или звуков. Воспроизводимые входные файлы находятся только в полном личном архиве исходников.
