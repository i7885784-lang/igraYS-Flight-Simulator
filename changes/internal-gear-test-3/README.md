# Шасси внутри корпуса — тест №3

Отдельная версия от Aircraft Fixes Test 2. Исправляет отвергнутые наружные
коробки ниш Су-27 и МиГ-29; прежние архивы сохранены.

Конвертер: `model-source/build_model.py`, Python 3 + `requirements.txt`.
Исходные AC3D и GPL-2.0/авторы сохранены в `model-source/upstream` и NOTICE.txt.
`fit_internal.py` подбирает складывание по исходной обшивке, `envelope.py`
содержит её опорную геометрию. Для отсутствующего исходного проёма передней
ниши Су-27 используется локальная заплата по нижней обшивке; фонарь входит
в верхний габарит, потолок ниши проверяется отдельно.

Створки повторяют исходный нижний контур. Стойки не скрываются. Колёса
основных стоек поворачиваются отдельно; передний амортизатор Су-27
сжимается при складывании. Новые две тяги и две серьги имеют общие шарниры.
Внутренние ниши не увеличивают внешний габарит самолётов.

`audit_internal.py`: собранные детали, двери и внутренние стенки в убранном
состоянии против исходной оболочки (дискретизация 25 мм, допуск 15 мм).
`sweep_internal.py`: 21 поза существующей анимации, проход через отверстия
и зазор под крышей ниши. Эти проверки не доказывают отсутствие всех
возможных пересечений; смотрите игровые фото/видео и ограничения отчёта.

Су-47 и поздняя ревизия Су-57 сохранены без изменения. Су-34 в этой публичной
версии отсутствует: его ресурсы пока находятся только в отдельной лаборатории.
Код движка и Win32 EXE те же, что в Test 2; `native.patch` повторно не накладывать.
Сборка движка описана в `../aircraft-fixes-test-2/README.md`.
Съёмка: Win64/Wine, Xvfb и FFmpeg. На настоящей Windows 10 x86 не запускалось.
