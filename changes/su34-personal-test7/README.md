Для воспроизведения установить `requirements.txt`, положить Су-34 из личного теста №6 в `baseline/su34.dnm`, исходный `su34_hi.yft` в `upstream/`, создать `runtime/aircraft`, выполнить `python build.py`, затем `SU34_CANDIDATE_PATH=candidate/aircraft/su34.dnm python nozzles.py`. Полный самостоятельный набор с этими данными включён в приватный архив исходников. `expected.json` содержит контрольные суммы просмотренной модели.
