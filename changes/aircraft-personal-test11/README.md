# Личный тест №11

Основа — полная №10. Преобразователь `fix_su34.py` читает `baseline/su34.dnm` и исходную оболочку `baseline/uncut-su34.srf`, использует `model-source/`, создаёт два DNM. Входные данные и библиотеки геометрии находятся в полном закрытом архиве исходников; новая чужая геометрия не добавляется.

Сборка модели: `pip install -r test11/requirements.txt`, `python test11/fix_su34.py`. Проверка пересечений выбранных деталей: `python test11/audit_su34.py`. Движок — как `test10/BUILD_ENGINE.md` в полном архиве. `native.patch` применяется к движку №10: газ не отбрасывает твердую тень, классы 2/110/111 используют аддитивное свечение в поставляемом GL1. Состояние смешивания восстанавливается; фон/корпус сохраняют проверку глубины. GL2/D3D не поставляются и этим изменением не проверялись.

[Отчёт и настоящие кадры](../../reports/personal-playtest-11/README.md). Windows 32-bit собирается; игровые проверки — Win64/Wine. Полная игра остаётся в закрытом черновике до выяснения прав Су-34.
