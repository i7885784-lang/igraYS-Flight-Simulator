# YSFlight Airshow v8.5 — продолжение полёта и настоящая пауза

**[Скачать полную игру для Windows 10, 32 бита](downloads/YSFlight_v8_5_32bit.zip?raw=true)**

Распакуйте ZIP целиком в новую папку, откройте `YSFlight_v8_5_32bit`, дважды нажмите **ysflight32_gl1.exe**. Альтернатива — `ysflight32_gl2.exe`. Окно сразу развёрнуто с обычной рамкой. Рабочую v8.4 сохраните.

## Пауза и продолжение

![Меню паузы](reports/v8_5/01-pause.png)

**Два Esc → «Продолжить»** возвращают в тот же полёт, без сброса положения и скорости. Сворачивание и переход в другое окно тоже включают паузу. Таймера бездействия нет. «Повторить полёт» отдельно начинает сначала.

«Создать новый полёт» открывается без предупреждения об удалении. Если отменить создание, можно продолжить прежний полёт.

## 8 ведомых, 10 строёв, 6 цветов

![Все оставшиеся строи на одной странице](reports/v8_5/02-formations.png)

Боковые лесенки убраны. Все варианты доступны на одной странице: **Enter → Сменить строй → 1–9, 0 или мышь**. Двойная колонна теперь включает игрока во главе одной из двух параллельных цепочек.

![Двойная колонна по сохранённым местам игры](reports/v8_5/08-double-column.png)

![Шесть цветов](reports/v8_5/07-palette.png)

Оставлены **чёрный, белый, синий, красный, зелёный, жёлтый**. Произвольный RGB убран из авиашоу. Цвет каждой машины меняется отдельно в F10.

## Управление и расстояние

По умолчанию — **клавиатура со стрелками**. При первом обновлении применяется клавиатурный вариант; затем мышь можно выбрать и сохранить в настройках.

Поле интервала принимает **10–5000 м**, стандарт — **50 м**. Фактический стартовый интервал защищён размерами моделей и запасом на торможение: большие самолёты не появляются внутри друг друга. Для проверенного F‑18E при введённых 10 м получилось около 35 м между центрами.

![Интервал 10 м в настройке](reports/v8_5/04-spacing.png)

## Разлёт и потеря ведущего

«Рассыпаться» задаёт самостоятельные курсы в пространстве, без автоматического сбора. В колонне выход по очереди; «Собраться» отзывает всех одновременно. После смертельного повреждения игрока ведомые прекращают следование за падающим самолётом.

## Управление

| Действие | Клавиши |
|---|---|
| Серия из 16 ловушек у игрока | **Ctrl+F** |
| Серия из 16 ловушек у всех | **Ctrl+Shift+F** |
| Меню дыма | **F10** |
| Команды ведомым и выбор строя | **Enter** |
| Внешняя камера выбранного самолёта | **F2** |
| Вращение / расстояние камеры | **ПКМ / колесо** |
| Кабина | **F1** |

В F10: **1** — дым, **2** — следующая машина, **3** — всем / выбранному, **4 / F10 / Esc** — продолжить полёт. Щёлкните имя справа для выбора самолёта; его цветной квадрат переключает индивидуальный цвет дыма. Настройка действует сразу. Кнопок ловушек в меню больше нет.

Для большого запаса ловушек включите оборудование авиашоу до вылета. На этой же вкладке можно изменить длину и интервал серии; 16 — значение по умолчанию. Текущие пользовательские назначения клавиш сохраняются; F10 также можно переназначить в настройках.
