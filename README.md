# YSFlight Airshow v8.8 — прикрытие для 1–8 ведомых

**[Скачать полную игру — Windows 10, 32 бита](downloads/YSFlight_v8_8_32bit.zip?raw=true)**

Распакуйте целиком в новую папку `YSFlight_v8_8_32bit`, дважды нажмите **ysflight32_gl1.exe**. Альтернатива — **ysflight32_gl2.exe**. Рабочую v8.7 сохраните.

## Своя схема для каждого состава

![Восемь вариантов прикрытия по данным игры](reports/v8_8/01-cover-counts.png)

**Enter → 6 → 1–8:** сколько ведомых отправить в прикрытие. **9 в этом меню — вернуть.** Доступен выбор мышью. Чётный состав — пары, нечётный — передняя тройка и следующие пары. Верхняя группа находится выше и позади игрока и строится независимо от основного строя.

![Выбор количества в настоящей игре](reports/v8_8/05-cover-menu.png)

## После потерь — новый компактный состав

![Перестроение восьми ведомых в семь](reports/v8_8/02-loss.png)

Верхняя и нижняя группы заполняют свои места отдельно. Номера обновляются; цвета дыма остаются у своих самолётов. Настоящее место игрока внизу не занимают.

## Следование с учётом возможностей самолёта

![Настоящие траектории Су-27 и МиГ-29](reports/v8_8/03-turn-paths.png)

При резких манёврах позиционное сближение мягче; обычный одновременный сбор возвращается после манёвра. Запрос набора ограничен тягой, сопротивлением, весом и запасом скорости. Исправлен расчёт интервалов частично отделённой группы и упреждающее торможение при обычном интервале 50 м.

Используется существующая физика YSFlight. Турбулентность и система потери визуального контакта не добавлялись. Построения — проект для игры, не боевое наставление.

**[Картинки и проверки](reports/v8_8/ПРОВЕРКИ.md)** · [Отчёт ZIP](downloads/YSFlight_v8_8_Report.zip?raw=true) · [Исходники](downloads/YSFlight_v8_8_Sources.zip?raw=true) · [SHA256](downloads/SHA256SUMS_v8_8.txt) · [Изменения кода](changes/v8_8.patch)

Проверены потери, разлёт и сбор, все восемь количеств прикрытия, набор и снижение, повороты с торможением и разгоном в смешанной группе, малая высота над OCEAN, меню и продолжение полёта после двух Esc. Геометрия прошла 3360 проверок расстояний.

Полётные испытания — Win64-сборка тех же исходников под Wine. Выдаваемые EXE — PE32/i386, Windows GUI, без CMD/BAT. Запуск на настоящей Windows 10 32 бит проверяет пользователь. Проверки не охватывают все модели, карты и любые манёвры.
