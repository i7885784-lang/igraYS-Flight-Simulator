# YSFlight Airshow v8.9 — исправления прикрытия и старта

**[Скачать полную игру — Windows 10, 32 бита](downloads/YSFlight_v8_9_32bit.zip?raw=true)**

Распакуйте целиком в новую папку `YSFlight_v8_9_32bit`, дважды нажмите **ysflight32_gl1.exe**. Альтернатива — **ysflight32_gl2.exe**. Предыдущую рабочую игру сохраните.

## Прикрытие всей группой

![Одна команда для всей группы](reports/v8_9/01-one-command.png)

**Enter → 6** — все живые ведомые переходят в прикрытие. Повторно **Enter → 6** — возврат. Количество выбирается перед полётом, отдельного выбора в воздухе больше нет.

## Переход без схождения в одну точку

![Этапы безопасного перестроения](reports/v8_9/03-transition.png)

Сначала ведомые расходятся по высоте, затем занимают горизонтальные места и только после этого собираются на общей высоте. Это условная схема; ниже — настоящий снимок игры после перехода всех шестерых.

![Все шесть ведомых в верхней группе](reports/v8_9/04-six-cover.png)

Переход выполняется обычным полётом и занимает время. В проверке через меню — около 47 секунд. Возврат и изменение состава после потери тоже используют разделение траекторий.

## Старт без самопроизвольного пикирования

![Проверка ручного воздушного старта](reports/v8_9/05-level-start.png)

Начальные тангаж, триммер и тяга рассчитаны после загрузки снаряжения. Игроку не включается скрытый автопилот: после изменения режима полёта управление и триммер остаются его задачей.

![Проверки из десяти исходных строёв](reports/v8_9/06-checks.png)

**[Картинки и подробности проверок](reports/v8_9/ПРОВЕРКИ.md)** · [Отчёт ZIP](downloads/YSFlight_v8_9_Report.zip?raw=true) · [Исходники](downloads/YSFlight_v8_9_Sources.zip?raw=true) · [SHA256](downloads/SHA256SUMS_v8_9.txt) · [Изменения кода](changes/v8_9.patch)

Проверены переходы из десяти строёв, возврат, потеря ведомого во время перехода, команда через настоящее меню и минутные ручные старты без нажатий на F-18E и МиГ-29. Подробные журналы и записи — в исходниках.

Полётные испытания — Win64-сборка тех же исходников под Wine. Выдаваемые EXE — PE32/i386, Windows GUI, без CMD/BAT. Настоящую Windows 10 32 бит проверяет пользователь. Проверки не охватывают все самолёты, карты, интервалы и любые манёвры.
