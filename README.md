# YSFlight Airshow v8.4 — 10 ведомых и новые строи

**[Скачать полную игру v8.4 для Windows 10, 32 бита](downloads/YSFlight_v8_4_32bit.zip?raw=true)**

Распакуйте целиком в новую папку, откройте `YSFlight_v8_4_32bit` и дважды нажмите **ysflight32_gl1.exe**. В заголовке — **Airshow v8.4**. Альтернатива — `ysflight32_gl2.exe`. Рабочую v8.3 сохраните.

## 10 ведомых + игрок = 11 самолётов

![Выбор десяти ведомых](reports/v8_4/06-wingmen.png)

«Новый полёт» → «Ведомые» → количество **10**. Девятый и десятый самолёты настраиваются отдельно; дым, камера и ловушки охватывают всю группу. Старые полёты сохраняют прежнее число машин.

## 12 строёв

![Все строи: схемы мест](reports/v8_4/01-formations.png)

Добавлены **лесенка вверх, лесенка влево, лесенка вправо, двойная колонна и обратный клин**. Лесенка задаёт намеренные ступени высоты — 20 м при дистанции 50 м.

Перед полётом: вкладка «Строй» → включить настройку → выбрать вариант. В воздухе: **Enter → Строй → Новые строи**. В ромбе и дельте новые самолёты получили собственные места.

## 15 цветов дыма

![Палитра](reports/v8_4/02-palette.png)

Есть **чёрный**, белый, синий, красный, жёлтый, зелёный, фиолетовый, оранжевый, голубой, розовый, серый, коричневый, тёмно-синий, салатовый и пурпурный. Одна палитра используется до полёта и в F10; произвольный RGB сохранён.

В **F10** нажимайте цветной квадрат рядом с машиной. В строке видно название выбранного цвета.

![Меню дыма в игре](reports/v8_4/03-smoke-menu.png)

## Управление

| Действие | Клавиши |
|---|---|
| Серия из 16 ловушек у игрока | **Ctrl+F** |
| Серия из 16 ловушек у всех | **Ctrl+Shift+F** |
| Меню дыма | **F10** |
| Команды ведомым и выбор строя | **Enter** |
| Внешняя камера выбранного самолёта | **F2** |
| Вращение / расстояние камеры | **ПКМ / колесо** |
| Кабина | **F1** |

В F10: **1** — дым, **2** — следующая машина, **3** — всем / выбранному, **4 / F10 / Esc** — продолжить полёт. Щёлкните имя справа для выбора самолёта; его цветной квадрат переключает индивидуальный цвет дыма. Настройка действует сразу. Кнопок ловушек в меню больше нет.

Для большого запаса ловушек включите оборудование авиашоу до вылета. На этой же вкладке можно изменить длину и интервал серии; 16 — значение по умолчанию. Текущие пользовательские назначения клавиш сохраняются; F10 также можно переназначить в настройках.
