# YSFlight Airshow v8.6 — разлёт и «Фронт пар»

**[Скачать полную игру — Windows 10, 32 бита](downloads/YSFlight_v8_6_32bit.zip?raw=true)**

Распакуйте целиком в новую папку `YSFlight_v8_6_32bit`, дважды нажмите **ysflight32_gl1.exe**. Альтернатива — **ysflight32_gl2.exe**. Рабочую v8.5 сохраните.

## Исправлен разлёт

![До и после — реальные траектории](reports/v8_6/01-before-after.png)

Ведомые уходят наружу, сохраняя защиту от сближения и земли. В колонне — по очереди, в остальных строях — одновременно. Возврат только по команде «Собраться». При смене строя свободные места распределяются по ближайшим маршрутам; номер и цвет сохраняются у самолёта.

![Проверены все десять строёв](reports/v8_6/02-all-formations.png)

## «Фронт пар» вместо двойной колонны

![Фронт пар по сохранённым местам игры](reports/v8_6/03-pairs.png)

Две машины рядом; следующая пара позади и сдвинута на половину интервала. Игрок входит в первую пару. Выбор до вылета и в воздухе: **Enter → Сменить строй → Фронт пар**.

![Выбор нового строя в игре](reports/v8_6/05-wheel.png)

Сохраняются 8 ведомых, 6 цветов дыма, клавиатура по умолчанию, пауза при сворачивании/смене окна и продолжение того же полёта. Для нового построения создайте новый полёт или отдайте соответствующий приказ в старом.
