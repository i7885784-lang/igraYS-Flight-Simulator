# YSFlight — меню по центру

Пробная сборка для Windows 10, 32 бит.

[Скачать игру ZIP](downloads/YSFlight_Center_32bit_TEST.zip?raw=true)

1. Полностью распакуйте архив в новую папку. Старую игру сохраните.
2. Откройте папку YSFlight_Center_32bit.
3. Дважды нажмите ysflight32_gl1.exe.
4. Проверьте главное меню, Create New Flight и выбор самолёта.

Оригинальные заменённые EXE находятся в backup_original_exe. Инструкция по откату — в READ_ME_RU.txt внутри архива.

Сборка 32 бит проверена; интерфейс и запуск полёта проверены на отдельной 64-битной сборке с теми же изменениями. Работа конечных EXE на Windows 10 32 бит требует проверки на вашем компьютере.

[Исходники, изменения и инструкции сборки](downloads/YSFlight_Center_Sources.zip?raw=true).
