# YSFlight v8.2 — строи, разлёт и дым

Для **Windows 10 x86, 32 бита**. Полная игра с моделями, картами и сохранёнными оригиналами.

**[Скачать игру v8.2 — ZIP](downloads/YSFlight_v8_2_32bit.zip?raw=true)**

Распакуйте ZIP целиком в новую папку. Откройте **YSFlight_v8_2_32bit** и дважды нажмите **ysflight32_gl1.exe**. Заголовок окна: **Airshow v8.2**. Старую рабочую папку сохраните для отката. Предыдущие изменённые файлы также лежат в `backup_v8_1`.

## Что изменено

- Более быстрое сближение с местом в строю и снижение к высоте ведущего. Скорость зависит от текущего движения ведущего; сохраняется ограничение против сваливания.
- Упреждающее расхождение при опасном сближении: боковое уклонение и разнесение по высоте.
- В клине «Разлёт» действует одновременно. В колонне — по очереди через 0,8 секунды. Через 8 секунд каждая машина начинает возвращение, в колонне тоже по очереди. «Собраться» отзывает раньше.
- После потери ведомого следующие самолёты занимают свободное место и получают непрерывные номера. Индивидуальные цвета сохраняются.
- Повторное «Прикрытие» отменяет приказ. «Отмена приказа / В строй» также возвращает ведомых.
- Ловушки вынесены на клавиши, цвета дыма меняются прямо в полёте.

## Управление

| Действие | Клавиши |
|---|---|
| Серия из 16 ловушек у игрока | **Ctrl+F** |
| Серия из 16 ловушек у всех | **Ctrl+Shift+F** |
| Меню дыма | **F10** |
| Команды ведомым и выбор строя | **Enter** |
| Внешняя камера выбранного самолёта | **F2** |
| Вращение / расстояние камеры | **ПКМ / колесо** |
| Кабина | **F1** |

В F10: **1** — дым, **2** — следующая машина, **3** — всем / выбранному, **4 / F10 / Esc** — продолжить полёт. Щёлкните имя справа для выбора самолёта; его цветной квадрат переключает индивидуальный цвет дыма. Настройка действует сразу. Кнопок ловушек в меню больше нет.

Для большого запаса ловушек включите оборудование авиашоу до вылета. На этой же вкладке можно изменить длину и интервал серии; 16 — значение по умолчанию. Текущие пользовательские назначения клавиш сохраняются; F10 также можно переназначить в настройках.

## Проверки и исходники

[Отчёт со снимками и графиками](reports/v8_2/ПРОВЕРКИ.md) · [ZIP отчёта](downloads/YSFlight_v8_2_Report.zip?raw=true) · [Исходники](downloads/YSFlight_v8_2_Sources.zip?raw=true) · [SHA256](downloads/SHA256SUMS_v8_2.txt)

Проверены разворот восьми F-18E, снижение, выход из пикирования, пересечение траекторий, вертолётный строй, поочерёдный разлёт/возврат, отмена прикрытия, замещение потерянного самолёта, торможение ведущего, новые клавиши ловушек и смена цвета мышью.

Полёты выполняются в Win64-сборке тех же исходников под Wine. Игровые EXE собраны для PE32/i386 с оконной подсистемой Windows GUI; запуск на настоящей Windows 10 x86 проверяет пользователь. Все модели и любые произвольные манёвры не охвачены проверками.

Сохранены исправления запуска v8.1 и предыдущие функции. Пользовательский раздел «Миссии» отключён: развиваем строи, ведомых и авиашоу. [Предыдущая рабочая v8.1](downloads/YSFlight_v8_1_32bit.zip?raw=true); остальные версии — в [downloads](downloads).
